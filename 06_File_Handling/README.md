# 📁 06_File_Handling: Input/Output & Stream Processing

This directory covers file operations, modes, and persistent data manipulation in Python.

---

## 📂 Contents

* **Core File Operations (`1.py`, `2.py`, `3.py`)**:
  * Opening, reading, writing, and closing files with safety.
  * Context managers (`with open(...) as f:`).
* **Access Modes**:
  * `a_mode.py`: Append mode (`'a'`).
  * `rplus_mode.py`: Read & Write mode (`'r+'`).
  * `wplus_mode.py`: Write & Read mode (`'w+'`).
  * `x_mode.py`: Exclusive creation mode (`'x'`).
* **📁 Theory**:
  * Conceptual notes and stream pointers (`seek()`, `tell()`).
