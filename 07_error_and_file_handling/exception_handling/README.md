# 🛡️ 05_Exception_Handling: Error Handling & Resilience

This directory covers robust error management in Python, ensuring applications handle unexpected runtime failures gracefully.

---

## 📂 Contents

* **Code Examples (`1.py` to `10.py`)**:
  * `try`, `except`, `else`, `finally` block mechanics.
  * Handling specific exceptions (`TypeError`, `ZeroDivisionError`, `ValueError`, etc.).
  * Raising exceptions manually with `raise`.
* **Custom Exceptions**:
  * `Custom_Exception.py` & `Custom_Exception1.py`: Creating and raising user-defined exception hierarchies subclassing `Exception`.
* **📁 Theory**:
  * `Exception_Keywords.sh`: Key terminology and exception handling flow summary.
