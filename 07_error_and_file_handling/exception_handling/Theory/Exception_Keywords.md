#TRY
This block is used to wrap the code that might cause an exception.
Python executes code inside try:
    i) If no error occurs -> Except is Skipped.
    ii) If error comes -> Control jumps to except.
Needs TRY or FINALLY block.


#EXCEPT 
This block is used to catch and handle exceptions that occur inside a try block.


#ELSE
When there is were no exception occured.

#FINALLY
Block of code that always execute , no matter what happens.
Can be without Except block.
