## 🚀 Navigation & Usage

1. **Self-Contained Folders:** Each subfolder contains both the problem statement (`Question_Sheet.txt` or `Questions`) and individual solution files (`assi1.py`, `assi2.py`, etc.).
2. **Execution:** Run any solution directly:
   ```bash
   python3 "Assignments/01_Basics/01_Input_Output/1.py"
   python3 "Assignments/02_Functions/01_Basics_and_Lambda/assi1.py"
   python3 "Assignments/03_Modules_and_Packages/01_Hospital_Management_System/main.py"
   ```
