# Day 2: Operators

## Explanation
Operators are special symbols used to perform operations on variables and values.

## Key Concepts
- **Arithmetic**: `+`, `-`, `*`, `/`, `//` (floor division), `%` (modulo), `**` (exponentiation).
- **Comparison**: `==`, `!=`, `>`, `<`, `>=`, `<=` (Return booleans).
- **Logical**: `and`, `or`, `not`.
- **Assignment**: `=`, `+=`, `-=`, etc.
- **Membership**: `in`, `not in`.
- **Identity**: `is`, `is not` (checks memory location).

## Code Example
```python
a, b = 10, 3
print(a // b) # 3
print(a % b)  # 1
print(a > 5 and b < 5) # True
```

## Task
Write a script that takes a number and checks if it is both strictly greater than 10 and divisible by 2 using logical and arithmetic operators.
