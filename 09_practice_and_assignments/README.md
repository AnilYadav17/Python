## 💡 How to Approach These Assignments

1. **Read the Question Sheet First:**
   Before viewing solutions, read `Question_Sheet.txt` in the subfolder.
2. **Attempt Independently:**
   Write your solution in a scratchpad or local terminal.
3. **Compare with Solution Files:**
   Numbered files (`1.py`, `2.py`, etc.) correspond directly to Question 1, Question 2 in the sheet.
4. **Notice Edge Cases:**
   Review boundary checks, empty inputs, and type conversions in each provided solution.
