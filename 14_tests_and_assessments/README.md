# 🧪 14_Tests_and_Assessments: Classroom Unit Tests & Mock Exams

## Overview
This directory captures the authentic timeline of academic milestones, periodic classroom unit tests, mock programming assessments, and evaluation problem sheets.

Unlike isolated textbook examples, these tests present **scenario-based problems** where algorithmic concepts (loops, strings, mathematics, database SQL) are mapped to practical domains: banking fraud checks, cricket player analytics, signal strength rendering, and string diffing.

## 💡 Educational Value for Learners

Reviewing these real-world test problems helps students:
1. Practice under time-bound exam conditions.
2. Translate complex problem specifications into working Python code.
3. Test against tricky edge cases (e.g., negative numbers, empty strings, mismatched lengths).
